# Final problem statements

Each domain has its own JSON file containing Problem Statement 01 and 02. Content comes from the matching domain and number in `Final_Problem_Statements_By_Domain.zip` supplied on 11 October 2026.

The full document wording is preserved. Repeated domain labels and title numbering are displayed by the page itself. Sections retain their original headings, paragraphs, bullet lists and evaluation tables. Participant instructions inside the briefs are displayed as content.

Edit the appropriate domain JSON to update a brief. `sections` supports `heading`, `paragraph`, `list` and `table` blocks, rendered by `../render-content.js`. Keep `problemNum` as `01` or `02` and preserve domain order in `../data.js`, which also matches the character pairs.

Page availability is controlled separately in the home menu and shared navigation. Updating these briefs does not enable the page.
